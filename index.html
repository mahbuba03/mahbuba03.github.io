Projects

Malware Signature Scanner (Educational)

Qt 6 Widgets, C++17, CMake. Course project for ICT-1200.

A desktop application that scans files and folders recursively against a database of known-bad hashes, flags matches and simulates quarantine by moving flagged files to a sandbox folder. It shows how signature-based antivirus works, using only harmless test files.

Key features

  • Recursive scan of files and folders
  • MD5 and SHA-256 hashing of each file
  • Matches files against a database of known-bad hashes
  • Simulated quarantine: flagged files move to a sandbox folder
  • Safe by design: works only with harmless test files

What I learned

  • How signature-based detection works in antivirus tools
  • Building a desktop GUI with Qt 6 Widgets and C++17
  • Organising a project with CMake and documenting it on GitHub
